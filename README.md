# Omagle (Omegle X)

**Developed by Ewaron**

Omagle is a cutting-edge real-time video communication platform designed to connect users globally through intelligent random matching and direct peer-to-peer interactions. Built with performance and privacy at its core, this application demonstrates Ewaron's expertise in developing scalable, low-latency web applications using modern web technologies.

## 🚀 Project Overview

Omagle reimagines the classic random chat experience with a modern, secure, and feature-rich interface. It leverages WebRTC for high-quality video/audio streaming and WebSockets for instantaneous signaling and messaging.

### Key Features

*   **Real-Time Video & Audio:** Seamless peer-to-peer streaming with low latency using WebRTC.
*   **Intelligent Matching System:** robust algorithms to pair users for random chats instantly.
*   **Direct User Connections:** Unique ability to view online users and request direct connections, moving beyond just random pairing.
*   **Instant Messaging:** Integrated real-time text chat with typing indicators and sound notifications.
*   **Privacy-First Architecture:** innovative design where video, audio, and chats are ephemeral and never stored on servers.
*   **Responsive & Modern UI:** A glassmorphism-inspired interface ("Omegle X") that provides a consistent experience across desktop and mobile devices.
*   **Creator Mode:** Special administrative features for content creators and moderators.

## 🛠️ Technology Stack

This project utilizes a robust full-stack environment:

*   **Backend:** Node.js, Express.js
*   **Real-Time Communication:** Socket.IO, WebRTC
*   **Frontend:** HTML5, CSS3 (Modern Animations & Layouts), Vanilla JavaScript
*   **Security:** Helmet.js, CORS management, Rate Limiting
*   **Utilities:** UUID for session management, GeoIP capabilities
